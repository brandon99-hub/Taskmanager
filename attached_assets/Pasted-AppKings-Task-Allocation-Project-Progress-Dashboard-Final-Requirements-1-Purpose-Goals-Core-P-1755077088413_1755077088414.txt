AppKings Task Allocation & Project Progress Dashboard — Final Requirements
1. Purpose & Goals
Core Purpose: Replace manual project tracking with an automated platform to:

Track ongoing projects in real-time.

Assign tasks/projects and ensure deadlines are met.

Spot underperformance quickly.

Additional Goals:

Performance evaluation — generate per-person productivity metrics.

Workload balancing — identify over/underloaded team members.

Historical archive — store completed projects and past reports.

Project Manager Role: Creates projects and oversees task distribution.

2. Project Management
Fields when creating a project:

Project Name

Description

Client (if applicable)

Start Date

End Date / Deadline

Assigned Team/Department

Project Manager

Budget (optional but useful for tracking)

Project Timeline

Attachments (docs/specs)

Projects can and should be split into tasks and subtasks.

Supports full project timelines for visual tracking.

Reassignment: Tasks can be reassigned if progress is lacking.

3. Task Management
Fields per task:

Task Name

Description

Priority (Low, Medium, High, Critical)

Start Date

Due Date

Assigned Staff

Estimated Hours

Dependencies

Attachments

Progress Tracking:

Auto-calculated from task completion.

Managers get alerts for overdue or stagnant tasks.

Staff updates may be manual but do not affect progress % calculation.

4. Dashboard Features
Visual Layout:

Simplified Kanban Board for ease of understanding.

Metrics: Ongoing projects, tasks by status, overdue count, workload per person, deadlines in next 7 days, completion rates.

Color-coded urgency indicators (Green/Yellow/Red).

Manager Drill-Down: Project → Tasks → Individual updates.

5. Reports
On-demand Excel export (PDF optional later).

Includes:

Project summary

Task list with statuses

Assigned staff & completion %

Overdue tasks/projects

Performance metrics per person/team

Past reports stored for audit/history.

6. Notifications & Alerts
Channels: Email (mandatory), optional in-app pop-ups.

Triggers:

Staff assigned a new task → email alert.

Manager alerted when:

Task is overdue.

Project is falling behind schedule.

7. Roles & Permissions
Roles:

Admin — full control.

Manager — assign tasks, view team progress.

Employee — update tasks, view own assignments.

Viewer — read-only access for higher management/clients.

Visibility: Employees can see both their own tasks and their team’s tasks.

8. Integrations
Google Calendar integration for deadlines.
