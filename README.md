# TaskFlow — Project Management Dashboard

TaskFlow is a monorepo that bundles an Express API with a Vite-powered React frontend to deliver a business-grade project, task, and finance control center with automation, alerts, and audited workflows.

## Overview

TaskFlow unifies project planning, task tracking, billing milestones, and team performance into a single dashboard. The API enforces strict security, auditability, and observability while the React client offers dashboards, Kanban boards, reporting, and notification canvases for admins, managers, and employees.

## Architecture

- **Server** (`server/`): Express + Passport-managed sessions backed by PostgreSQL + Drizzle ORM. Middleware enforces security headers, CORS, CSRF protection, rate limiting, comprehensive auditing, and automated logging. Vite middleware serves the client in development mode.
- **Client** (`client/`): React (with hooks, Radix UI, Tailwind CSS, framer-motion) bootstrapped by Vite. Shared schema definitions in `shared/` keep the client and server aligned on DTOs, enums, and validation.
- **Shared Assets**: `shared/schema.ts` defines Drizzle tables, enums, and validation helpers; `server/templates/` houses Handlebars email templates; `migrations/` captures schema history generated by `drizzle-kit`.

## Features

- **Project lifecycle**: Create projects with segmentation, budgets, phases, milestones, and probability-based progress.
- **Task orchestration**: Modules → Subtasks → Dependencies → Kanban boards featuring priorities, status, and weight-based progress calculations.
- **Team & role security**: Team rosters, admin roles (project managers, finance heads, segment leaders), and middleware-enforced permissions.
- **Dashboards & reporting**: Metrics, workload breakdowns, overdue summaries, and Google Calendar/email reminders for tasks and milestones.
- **Automation**: Scheduled checks for module deadlines and contract expirations plus comprehensive auditing of critical actions.
- **Notifications**: In-app counters, templated emails (task assignments, due soon, overdue, project deadlines, password resets), and optional SMTP/Gmail delivery.
- **Security hardening**: Rate limiting, CSRF, helmet security headers, session rotation, encrypted refresh tokens, password-strength feedback, account lockout tracking, and logging.
- **Data management scripts**: Excel imports, project wipes, password fixes, and targeted user updates are accessible via `scripts/`.

## Directory Layout

- `server/`: API entry point (`index.ts`), auth/session setup, middleware (security, CSRF, marketing auth, auditing), services (email, calendar, notifications), storage helpers, and static assets.
- `client/`: Vite-powered React SPA with `pages/`, `components/`, `hooks/`, and `lib/` utilities.
- `shared/`: Drizzle schema definitions, marketing and notification types, and constants shared between server and client. Enables type-safe SQL queries and Zod validation in both layers.
- `scripts/`: Operational helpers (`create-admin`, Excel imports, user resets, team management helpers, etc.).
- `migrations/`: `drizzle-kit` snapshots and SQL migrations that define the database history.
- `templates/`: Handlebars templates for auto-generated emails existed in `server/templates/`.
- `dist/`: Client build output served in production.

## Tech Stack

- **Backend**: Node 20+, Express, Passport.js, Drizzle ORM, PostgreSQL, Passport Local strategy, Winston logging, Nodemailer for emails, Google Calendar integration, rate-limiter-flexible/express-rate-limit.
- **Frontend**: Vite + React + TypeScript + Tailwind CSS + Radix UI + framer-motion + React Query + Charting/analytics libraries.
- **Tooling**: Drizzle Kit migrations, tsx for server runtime, ESLint/TS built in via `npm run check`, Tailwind tooling.

## Getting Started

### Prerequisites

- Node.js 18+ (20.x recommended)
- npm 10+ (or Yarn/Nx that can run npm scripts)
- PostgreSQL database reachable via `DATABASE_URL`
- (Optional) Gmail or SMTP credentials for email delivery, Google OAuth credentials for calendar sync

### Environment Variables

Copy `.env` from the example (or create fresh) and configure:

- `DATABASE_URL`: PostgreSQL connection string (required)
- `NODE_ENV`: `development`/`production` (default `development`)
- `PORT`: HTTP port (default `5000`)
- `SESSION_SECRET`: session signing key
- `SESSION_IDLE_TIMEOUT_MINUTES`: optional idle timeout (defaults to 30)
- `JWT_SECRET`: used for encrypted tokens
- `BCRYPT_ROUNDS`: password hashing cost (default 12)
- `RATE_LIMIT_WINDOW_MS`, `RATE_LIMIT_MAX_REQUESTS`, `AUTH_RATE_LIMIT_MAX`: security throttling
- `TRUST_PROXY`: set to `1` when behind a proxy/load balancer
- `COOKIE_DOMAIN`, `COOKIE_SECURE`: optional domain/secure flag for cookies
- `EMAIL_PROVIDER`: `gmail` or `smtp`
- `GMAIL_USER`, `GMAIL_APP_PASSWORD`: required when using Gmail provider
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `EMAIL_FROM`: SMTP relay configuration
- `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REDIRECT_URI`: needed for optional calendar sync
- `FRONTEND_URL` / `CLIENT_URL`: canonical front-end URL used in email/calendar links

### Install & Bootstrap

```bash
npm install
npm run db:push
npm run setup:admin
```

`db:push` runs `drizzle-kit` against `shared/schema.ts` and populates all tables (`users`, `teams`, `projects`, `modules`, `milestones`, `subtasks`, `project_phases`, etc.). `setup:admin` seeds an initial admin (`admin@taskflow.com / Admin123!`); change the password immediately via the UI.

## Development Workflow

- `npm run dev`: launches `tsx server/index.ts`, which sets up Express middleware, Vite middlewares (HMR, template transformation), and automation intervals. Access `http://localhost:5000`.
- Frontend assets load from `client/src`. Shared files (e.g. `shared/schema.ts`, `shared/notificationSchema.ts`) are available through Vite path aliases (`@`, `@shared`).
- Use `npm run check` to run TypeScript type checks before committing.

## Production Deployment

- `npm run build`: builds the React client (rooted at `client/`) and outputs to `dist/public`. Express serves these static files for non-API requests while API routes stay under `/api`.
- Configure `NODE_ENV=production`, `TRUST_PROXY=1` (if behind a proxy), and production-level secrets (`SESSION_SECRET`, `JWT_SECRET`, etc.).
- Run `npm start` (same as `npm run server`); it serves both API and static assets on the configured port.

## Database & Migrations

- Schema is defined in `shared/schema.ts` and shared between backend SQL queries and Zod validation.
- `drizzle-kit` configuration is in `drizzle.config.ts`; migrations live under `migrations/` and can be generated/regenerated with `npx drizzle-kit --help`.
- For more context, see `DATABASE_SETUP.md` for visualization of the project/phase/module/subtask/milestone relationships and simple troubleshooting tips.

## Automation & Utilities

- On boot, `server/index.ts` runs automation checks (`storage.checkModuleDeadlines`, `storage.checkContractExpirations`) and repeats them every 6 hours.
- Maintenance scripts in `scripts/` address data tasks:
  - `npm run fix:passwords`, `npm run fix:condensed` – data hygiene
  - `npm run import:projects`, `npm run import:users:excel`, `npm run test:excel:*` – Excel imports
  - `npm run wipe:projects`, `npm run remove:users` – data resets
  - `npm run update:segment:private` + helpers – marketing/private segment management
  - `npm run send:test:email` – email delivery testing
- `server/services/emailService.ts` and `server/services/calendarService.ts` wrap Nodemailer and Google Calendar APIs; configure via the environment variables listed above.

## API Snapshot

- **Auth**: registration, login/logout, forgot password, `GET /api/auth/user`
- **Dashboard**: `/api/dashboard/metrics`, `/workload`, `/upcoming-tasks`, `/overdue-tasks`, `/overdue-breakdown`, `/overdue-combined`
- **Projects/Modules/Milestones**: CRUD operations, terminate projects, export Excel (`server/utils/excelExport`), attachment uploads, progress calculations
- **Tasks/Subtasks**: list/create/update, weight/priority/responsiveness, dependencies, notifications (emails, in-app)
- **Teams & Users**: list teams, fetch user assignments, admin role checks, notifications
- **Marketing**: routed through `server/routes/marketing.ts` to serve marketing-specific dashboards and pipelines
- **Audit/Security**: comprehensive audit middleware logs `logProjectAction`, `logTeamAction`, `logInvoiceAction`, and tracks auth/validation events (`server/middleware/comprehensiveAudit.ts`, `server/utils/logger.ts`)
